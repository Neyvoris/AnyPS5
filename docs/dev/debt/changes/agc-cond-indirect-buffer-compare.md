# libSceAgcDriver

## change (`sceAgcCbBranch`) runs only with the always-pass compare function

- A [COND_INDIRECT_BUFFER](../../../core/libs/prx/libSceAgcDriver/Execution/src/Driver/Queues/Submission.cpp) (`sceAgcCbBranch`) with compare function 1 to 6 evaluates `(*compareAddress & mask) <function> reference` over 64 bits when the queue reaches the packet, from AMD's public PM4 layout; not measured on a console. True runs the first buffer; false runs the second in mode 2 and nothing in mode 1, and the branch replaces the rest of its buffer. Modes 1 and 2 are assumed to be if-then and if-then-else. Function 7, a predicated packet, a branch inside a COND_EXEC range, a REWIND, a flip or a rendering wait in either buffer throw. Both buffers are copied at submit, so a buffer the GPU rewrites later runs as copied. [sceAgcCbBranch](../../../core/libs/prx/libSceAgc/Cb/src/Branch.cpp) does not check the compare address of an always-pass branch or an empty buffer's address, as PPSA14632 passes an uninitialised compare address and a null else buffer.
